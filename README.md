# Yausig Churikuna · Ropa indígena

Página web de **Yausig Churikuna**, el local de ropa indígena de Mary en Quito, Ecuador: prendas tradicionales, bordados y accesorios que mantienen viva nuestra cultura.

## Secciones

- Portada
- Beneficios
- Categorías
- Ofertas con botón directo a WhatsApp
- Nosotros
- Contacto

## Tecnologías

- HTML5, CSS3 y JavaScript
- [Bootstrap 5](https://getbootstrap.com/)
- Publicada en Netlify

## Estructura

- `index.html`: la página
- `css/styles.css`: nuestros estilos y colores
- `js/main.js`: crea las ofertas y los enlaces de WhatsApp (el número va en `const WHATSAPP`)
- `img/`: logo y fotos

## Cómo verla en tu computadora

1. Clona el repositorio.
2. Abre la carpeta en VS Code.
3. Clic derecho en `index.html` → **Open with Live Server**.
