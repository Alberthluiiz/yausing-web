# Yausing · Ropa indígena

Página web de **Yausing**, el local de ropa indígena de Mary en Quito, Ecuador: prendas tradicionales, bordados y accesorios que mantienen viva nuestra cultura.

## Secciones

- Portada
- Categorías
- Ofertas con botón directo a WhatsApp
- Nosotros
- Contacto

## Tecnologías

- HTML5 y CSS3
- [Bootstrap 5](https://getbootstrap.com/)
- Publicada en Netlify

## Estructura

- `index.html`: la página
- `css/estilos.css`: nuestros estilos y colores
- `img/`: logo y fotos

## Cómo verla en tu computadora

1. Clona el repositorio.
2. Abre la carpeta en VS Code.
3. Clic derecho en `index.html` → **Open with Live Server**.
